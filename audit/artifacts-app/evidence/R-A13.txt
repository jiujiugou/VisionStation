== R-A13 Trigger:Mode 是死配置 ==
-- 配置侧（appsettings.json 的 Trigger 段）--
{
  "Trigger": {
    "Mode": "Manual",
    "TimerIntervalMs": 2000
  }
}

-- 代码侧：谁读了 Trigger:* --
src/VisionStation.App/Services/ServiceCollectionExtensions.cs:67:            new TimerTrigger(int.Parse(config["Trigger:TimerIntervalMs"] ?? "2000")));

-- 注册处：ITriggerSource 的唯一实现 --

        services.AddSingleton<ITriggerSource>(sp =>
            new TimerTrigger(int.Parse(config["Trigger:TimerIntervalMs"] ?? "2000")));

结论: 配置里声明了 Trigger:Mode=Manual，源码中 0 处读取该键；ITriggerSource 恒为 TimerTrigger。
      改这一项对行为没有任何影响，也没有任何日志提示它被忽略。
