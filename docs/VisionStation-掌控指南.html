0. 项目定位

VisionStation 是一个 WPF 桌面工业视觉检测工作站，目标是别人敢放到产线上跑。

产品形态：一个 Windows exe，双击运行。不需要 .NET 运行时、不需要数据库服务、不需要联网。

核心技术：.NET 8 + WPF + OpenCvSharp4 + SQLite + Serilog。

当前版本：V1.5。已完成基础框架(30分) + 工具框架(30分) + Pipeline(20分) + 工程质量(18分)，总计约 95 分。

三、6 层架构穿透

App 层 (WPF)

VisionStation.App/

职责：UI 界面 + ViewModel + Messenger 通信。依赖 Core、Devices、Storage、Service。
核心文件：App.xaml.cs（入口）、MainViewModel.cs（编排）、Messages.cs（消息）、5 个 View + ViewModel 对。

Service 层

VisionStation.Service/

职责：纯业务逻辑，零 UI 依赖。被 App 引用。
核心文件：HealthChecker.cs（自检）。

Core 层

VisionStation.Core/

职责：纯算法，零外部依赖。不引用任何 UI 框架。
核心文件：IVisionTool.cs（接口）、Pipeline.cs（编排）、Tools/*（三个检测器）、Models/*（数据模型）。

Devices 层

VisionStation.Devices/

职责：硬件抽象。依赖 Core（OpenCV Mat 类型）。
核心文件：ICamera.cs、ITriggerSource.cs、IDevice.cs 三个接口 + 各自实现。

Storage 层

VisionStation.Storage/

职责：数据持久化。依赖 Core。
核心文件：InspectionDbContext.cs（EF）、InspectionRepository.cs（CRUD）、ImageStoreService.cs（图片）。

Watchdog 层

VisionStation.Watchdog/

职责：独立进程，守护主进程。零依赖，纯控制台。

六、一次检测的全链路

1 触发：ControlPanelVM.StartDetection → TimerTrigger.Fire() → Triggered 事件
2 入口：MainViewModel.OnTriggered → Dispatcher 切 UI 线程 → ProcessFrame
3 采图：SwappableCamera.Capture() → ICamera.Capture() → Mat(640×480)
4 日志：ILogger 记 [采图尺寸] 原始图像: 640x480 px
5 检测：Pipeline.Run(image, rois, calib)
6     ├─ 转灰度 → CvtColor BGR2GRAY
7     ├─ 记 [ROI裁切] 日志
8     ├─ for(tool in tools)：
9     │   ├─ 匹配 ROI（名字→索引→重用末位）
10     │   ├─ tool.Execute(gray, roi) → ToolResult{IsOk,Summary,Metrics,Overlays}
11     │   └─ 异常捕获 → ToolResult.Ng("异常:...")
12     └─ InspectionReport{Results={"Presence":...,"Dimension":...,"Defect":...}}
13 标注：DrawAnnotations → 遍历 DrawCommands → Cv2.Rectangle/Circle/DrawContours → 水印 OK/NG
14 持久化：ImageStore.Save → Repository.SaveAsync → SQLite
15 通知：发 InspectionResultMessage → ResultPanelVM + LogPanelVM + StatusBarVM 各自更新
16 性能：CycleTime 记录 → StatusBar 更新

八、配置系统

配方文件（产品级，换产品就换这个）

十、破坏性实验（验证你真的懂了）

  1. 删掉 default.json → 启动 → 自检报告配方 FAIL → 用内置默认值 → 检测正常
  2. PresenceTool.Execute 里 throw → 点检测 → Pipeline 捕获 → 返回 ToolResult.Ng → 其他 Tool 继续跑
  3. 注释掉 _isProcessing → 自动模式每秒两帧 → 并发 Mat 操作 → AccessViolationException
  4. ROI 编辑器画框 → 保存 → 不重启 → 点检测 → 框立刻生效（RoisUpdatedMessage 热更新）
  5. Camera:Mode 写 "Webcam" → 启动 → 点检测 → 实时摄像头画面
  6. F2 → 拖框 → Delete → 保存 → F2 退出 → ROI 编辑器完整交互
  7. Ctrl+Shift+B → dotnet publish -r win-x64 --self-contained → 输出文件夹拷到另一台电脑 → 双击运行
  8. dotnet test VisionStation.UnitTests → 8 个测试全绿

十一、面试讲稿（5 分钟版）

"这是一个 WPF + OpenCV 的工业视觉工作站，6 层架构，目标是能在产线上 7×24 运行。

核心设计是 IVisionTool 抽象 + Pipeline 模式——所有检测工具（模板匹配、尺寸测量、缺陷检测）实现统一接口，Pipeline 遍历执行。加新检测算法只需写一个类实现 IVisionTool，Pipeline 一行不改。

设备层做了 ICamera 抽象——三种实现：文件模拟相机、USB 摄像头、海康工业相机。运行时可以热切换。将来接 PLC 通信也只是加一个 ITriggerSource 实现。

工程上做了看门狗进程守护、5 项开机自检、后台管家定期清理内存和过期数据、配方文件配置化、Serilog 文件+界面双日志、8 个单元测试。整个 Core 层零 UI 依赖，可以脱离 WPF 在控制台里跑。

技术栈：.NET 8、WPF MVVM、CommunityToolkit.Mvvm Messenger 解耦、OpenCvSharp4、SQLite+EF Core、Serilog、xUnit。部署包 260MB，自包含不依赖 .NET 运行时，拷到任何 Win10/Win11 电脑双击即跑。"
