# 2026-10-23 追加（20:30）：全局脚本路线与脚本 API 清单

用户明确要求：VM 侧不要再点点点，写脚本。

## 已从部署 DLL 核实的脚本 API

`VM.GlobalScript.Methods.UserGlobalMethods` 的方法（用 System.Reflection.Metadata 读元数据得到，未加载程序集）：

- `InitSDK()` / `InitAfterLoadSol()` / `DefaultExecuteProcess()`
- `ExecuteProcessOnce(processName, strCommand)` / `ContinuousExecuteProcess(processName)`
- `SetScriptContinuousExecuteInterval(milliseconds)` / `GetScriptContinuousExecuteInterval()`
- `StartGlobalCommunicate()` / `StartTryGlobalCommunicate()` / `RegesiterReceiveCommunicateDataEvent()`
- `SendCommDeviceData(string sendString, int deceiveID, int addressID, DataType dataType)`（另有 byte[] 重载）
- `GetGlobalVariableIntValue/FloatValue/StringValue`、`SetGlobalVariable*Value`
- `GetProcessList()`、`ConsoleWrite(content)`、`Sleep(ms)`
- 可 override 的 `ResultDataCallBack(outputPlatformInfo, puser)`

`DataType` 枚举：`StringType / IntType / FloatType / ByteType`

通信设备编号从 1 开始，与「通信管理」设备列表顺序一致。
