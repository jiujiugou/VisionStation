## 维护约定

- 新增修复**不再**在代码注释里写编号，编号只在本文件登记。
- 代码注释只回答"为什么这样做"，不写"以前怎么错的"——除非错误本身是约束来源（例如"停 Timer 不会停住正在跑的那一轮"）。
- 本文件与 `docs/WPF规范落地记录.md` 的 W-xx 是两套编号：W = WPF 改造偏差，F/R = 运行期缺陷。
- 代码里的 `ADR-xxx` 是架构决议编号（见 `notes/ADR/`），与事故编号不同体系，可以保留。
