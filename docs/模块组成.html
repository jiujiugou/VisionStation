VisionStation 模块组成

按业务职责聚合 · 主链路三个模块 + 交互层，配方 / 运维 / 回归验证为支撑

模块组成

依赖单向：交互层 → 采集 → 检测引擎 → 存储；配方驱动检测引擎；支撑模块不反向依赖主链路

模块清单

模块 回答的问题 代码落点 边界规则
采集 图从哪来、什么时候拍 Devices：ICamera×3 实现（海康 / 文件 / 摄像头）、ITriggerSource、DeviceManager 只吐 CameraFrame，不认识配方
检测引擎 图里有什么、合格吗 Core：Pipeline + 4 个工具 + Calibration 输入帧、输出报告，零框架依赖，可被跑批器直接复用
配方 检什么、多严 Core/Models/RecipeConfig + App 加载逻辑 + Config/recipes/ 单一真相源，磁盘与内嵌资源为同一份文件
存储 结果去哪、留多久 Storage：InspectionRepository + ImageStoreService 只认 InspectionReport，换数据库只动本模块
交互 人怎么操作系统 App：Views + ViewModels + Converters 只编排，不写业务规则
运维 系统好不好、能跑多久 Service：HealthChecker + HousekeepingService + Watchdog 收明确参数，不读配置文件
回归验证 改动坏没坏 tests/GoldenSet/ + tools/GoldenSetRunner/ 验证以上所有模块，独立进程运行
