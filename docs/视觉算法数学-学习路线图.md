# 视觉算法数学 — 该学吗？怎么学？（为长期铺路）

> 适用对象：VisionStation 项目作者，目标岗位"视觉软件 / 上位机工程师"，零算法数学基础。
> 核心结论一句话：**面试前不学数学；入职后按需学、先直觉后公式；想转算法岗再系统性深入。**

---

## 1. 先定个调：学，但要分清时机

数学是"遇到问题时的地图"，不是"进门时的门票"。

| 阶段 | 该不该学数学 | 原因 |
|---|---|---|
| **面试前（现在）** | ❌ 不学 | 视觉软件岗面试不考推导，问的是"会用、会调、会讲"。时间应花在速成文档 + 调参 + 项目补齐上 |
| **入职第 1 年** | ✅ 按需学 | 真实工作里遇到问题才需要对应的数学，遇到了再查、再弄懂 |
| **想转算法岗（2~3 年后）** | ✅ 系统学 | 那才需要真正补推导和理论 |

你现在最该做的，是**先把 offer 拿到手**，而不是用宝贵的面试准备时间啃数学。数学是入职后的事。

---

## 2. 该学哪些数学（按对你工作的重要度排序）

下面每一个都**绑到你项目里已有的东西**——你学的时候，就说得出"这个数学就是我代码里那个 X"。

### ① 线性代数（矩阵、向量）—— 最重要
- **对应你项目**：图像本身就是一个像素矩阵；模板匹配的旋转问题 = 矩阵变换问题；相机模型的内参矩阵 = 你 Calibration 的短板。
- **要懂的**：矩阵乘法 = 变换（旋转/缩放/平移）；图像 = 矩阵；坐标变换。
- **直觉来源**：B 站 3Blue1Brown《线性代数的本质》。

### ② 坐标系统与变换（图像 ↔ 世界 ↔ 相机）—— 直接对应你的标定
- **对应你项目**：`CoordinateMapper`（屏幕↔图像）就是雏形；工业里往上走是"相机↔机械手"手眼标定。
- **要懂的**：针孔相机模型、内参/外参、单应矩阵 homography、仿射变换、张正友标定。
- **直觉来源**：高翔《视觉SLAM十四讲》只看"相机几何"章节，讲得最清楚。

### ③ 微积分基础（导数、梯度）—— 理解"边缘"
- **对应你项目**：导数 = 变化率 = 梯度 = 边缘。Sobel / Canny 边缘检测全是梯度；你的霍夫圆 param1 就是 Canny 梯度阈值。
- **要懂的**：导数就是"变化率"，梯度就是"往哪个方向变化最快"。不用会求导技巧，看懂概念即可。
- **直觉来源**：3Blue1Brown《微积分的本质》。

### ④ 统计基础（均值、方差、正态、相关）—— 理解阈值与模板匹配
- **对应你项目**：模板匹配的 `CCoeffNormed` 就是**相关系数**，一个统计概念；你天天碰的误检/漏检 = 假阳性/假阴性，属于统计里的 ROC 概念。
- **要懂的**：均值/方差（图像亮度分布）、相关系数（模板匹配）、正态分布（噪声）。

### ⑤ 概率 —— 理解"置信度、误检漏检率"
- 后面如果接触 AI / 检测报表统计，用得着。第 1 年知道"概率 = 不确定性的量化"即可。

### ⑥ 傅里叶变换 —— 最不急
- 用于频域滤波，工业场景用得少。第 1 年**懂概念**（"把信号拆成不同频率"）就够了，别深挖。

## 3. 怎么学（方法论，比学什么更重要）

### 原则 1：先直觉，后公式
先看 3Blue1Brown 建立"这个东西到底在干嘛"的画面感，再看公式就不怕了。

### 原则 2：按需学（Just-in-time），不按教材顺序啃
遇到项目里的实际问题 → 查对应的数学 → 只弄懂能解决这个问题的部分 → 记进笔记。**别从头到尾读教材。**

### 原则 3：每个概念绑一个项目里的函数
学完一个概念，要能说出"这个矩阵 = 我 Calibration 里的换算""这个相关系数 = 我 MatchTemplate 的分数"。

### 原则 4：不刷题海
你不是去考研。**看得懂公式在表达什么**，就够 90% 的工业场景。不需要手算行列式、积分。

## 5. 分阶段执行路线

### 阶段 A：现在 → 拿到 offer
- ❌ 不碰数学。
- ✅ 按《视觉算法面试速成-人话版》准备 + 用 Test 项目调参。

### 阶段 B：入职第 1 年（每周 1~2 小时）
- 按重要度顺序：线性代数 → 坐标变换/相机模型 → 微积分/梯度 → 统计/相关。
- 用 3Blue1Brown 建立直觉；遇到工作问题顺手查对应数学并记录。
- **验收标准**：看得懂公式在表达什么；能把你项目的标定、模板匹配、边缘检测讲成数学语言。

### 阶段 C：第 2~3 年想转算法岗
- 才需要系统补：优化理论（梯度下降）、概率模型、深度学习数学（反向传播/损失函数）。
- 那时再决定是否走算法路线，不必现在焦虑。

---

## 6. 一句话总结

> 视觉软件工程师的成长路径是"**先会用，后懂理**"。面试拿票不需要数学；入职后把它当地图，遇到问题再翻。别让"数学焦虑"耽误了你现在最该做的两件事：**拿下 offer、把项目讲透。**
