# 黄金样本库

> 一句话：把「改完算法我觉得更准了」变成「漏检从 6 个减到 4 个，跨类误报框从 14 个增到 15 个」。
>
> 建立日期：2026-10-18 · 数据：NEU-DET 钢材表面缺陷测试集子集 105 张

---

## 一、它解决什么问题

视觉算法没有"改完了"这个状态。调一个阈值、换一次预处理、换个权重，指标就会动，但**方向对不对没人知道**——

没有黄金样本库时，验证方式是"打开几张图看看，嗯，好像框得更准了"。
这套方式有三个致命问题：

1. **样本不固定**：这次看 5 张，下次看另外 5 张，没法比。
2. **只记得改好的**：改坏了那几张，人的注意力天然会漏掉。
3. **说不出口**：面试问"你怎么知道改完更好了"，只能答"感觉"。

黄金样本库把这件事变成一次命令、一张表、一个退出码。

---

## 二、组成部分

| 文件 | 作用 | 是否入库 |
| --- | --- | --- |
| `tests/GoldenSet/dataset.json` | 样本清单：路径 + 图像级真值 + SHA256 前 16 位 + 尺寸 | 是 |
| `tests/GoldenSet/baseline.json` | 上一次确认无误的逐图结果快照 | 是 |
| `tests/GoldenSet/last-run.json` | 本次运行结果（每次覆盖） | 否（.gitignore） |
| `tools/GoldenSetRunner/` | 跑批器：加载模型 → 走真实 Pipeline → 评估 → 对比 | 是 |
| `TestImages/RealParts/NEU-DET/` | 105 张源图（1.9MB） | 是 |

**为什么用 SHA256 锁数据？**
数据集本身是"标准"，标准变了，历史对比就全失效了。清单里记录每张图内容哈希，图片被替换、被压缩、被误删都会在 `verify` 阶段直接报错，而不是安静地给出一个不同的分数。

---

## 三、三条命令

```bash
# 1. 校验数据集完整性（不加载模型，秒级）
dotnet run --project tools/GoldenSetRunner -- verify

# 2. 跑批 + 与基线对比（105 张约 18 秒）
dotnet run --project tools/GoldenSetRunner

# 3. 确认本次结果无误后，把它写成新基线
dotnet run --project tools/GoldenSetRunner -- --update-baseline
```

其他参数：

```bash
--conf 0.30          # 改置信度阈值
--nms  0.50          # 改 NMS IoU
--limit 20           # 只跑前 20 张（调试用，别拿来更新基线）
--out <path>         # 结果输出位置
```

**退出码**：`0` 无回归 · `1` 有回归 · `2` 运行失败。可以直接接 CI 当门禁。

## 四、判定三态

数据集全部是"有缺陷"的图，所以每张图只有三种结局：

| 判定 | 定义 | 为什么这样分 |
| --- | --- | --- |
| **命中 Hit** | 检出了真值类别的框 | 算法把该看见的看见了 |
| **错分 Misclassified** | 有框，但没有一个框是真值类别 | 模型看见了东西，但认错了 —— 说明特征提取有效、分类边界有问题，是**可调**的 |
| **漏检 Missed** | 一个框都没有 | 算法完全没看见 —— 最严重，直接导致漏放 |

把"错分"和"漏检"分开，是为了让改进方向可判断：错分多 → 调类别阈值/后处理；漏检多 → 查预处理/模型容量。压成一个"准确率"就什么都看不出来。

**跨类误报框（otherClassBoxes）**：判定为命中的图里，非真值类的那些框也记账。一张图命中了 crazing，但同时还框了两个 patches，说明模型在这张图上不确定——这类噪音上产线会变成过杀。

## 五、输出怎么读

```
数据集  v1.0 · 105 张 · crazing 27 / inclusion 30 / patches 30 / pitted_surface 18
模型    models/neu-det.onnx  sha 01c634a7165c0afa  conf 0.25  nms 0.45
耗时    18.0s（均 136ms/张，P95 177ms）

── 分类别 ──
类别              样本  命中  错分  漏检  跨类误报  严格召回
crazing             27    26     0     1         0     96.3%
inclusion           30    30     0     0         2    100.0%
...

── 总体 ──
命中(真值类检出)   104/105    99.0%
漏检(一个框都没)     1/105     1.0%
跨类误报框          14 个
未覆盖类别        rolled-in_scale, scratches（数据集无样本，指标不可用）

── 与基线对比（2026-10-18T20:53:29 → 2026-10-18T20:56:13）──
变好  1 个
    [修复漏检] crazing_294            检前:- → 检后:crazing:3
跨类误报框  +1（14 → 15）
```

对比段是全部价值所在。「变差 / 变好 / 细节变化」分开列，变差按严重度排序（新漏检排最前），这样扫一眼就知道这次改动值不值。

> 上面示例的对比段取自一次阈值实验（conf 0.25 → 0.15）：修复 1 个漏检，代价是多 1 个误报框——正是这类权衡需要被看见。

**注意 `未覆盖类别` 这一行**：数据集里没有的类别，指标里查不到，很容易被误读成"该类 100% 通过"。所以它必须显式打出来。

## 六、基线纪律

这套东西只有在**基线可信**的前提下才有效。三条规矩：

1. **改完算法 → 先跑 → 看对比表 → 确认方向对了 → 才更新基线。**
2. **不看对比表就 `--update-baseline`，等于把门禁拆了。** 每次都能"通过"，因为标准跟着结果走。
3. **换模型权重必须同时更新基线**（报告里记了模型 SHA，能看出是不是换了权重）。

`baseline.json` 入库、`last-run.json` 不入库 —— 前者是版本锚点，后者是临时产物。

---

## 七、已知边界（必须诚实标注）

这套东西不是万能的，边界很清楚：

| 局限 | 后果 | 补齐方式 |
| --- | --- | --- |
| 只覆盖 4/6 类（缺 `rolled-in_scale`、`scratches`） | 这两类退化了看不出来 | 把 NEU-DET 对应类别的图补进数据集，重算 SHA |
| 全是有缺陷图，**没有 good 样本** | 算不了**过杀率**（把好件判坏的比率） | 采正常件图，或用现场数据；这是最该补的一项 |
| 图像级真值，无框级标注 | 算不了 mAP / IoU 定位精度 | 转 YOLO 格式标注，评估升级到框级 |
| 单一数据源（NEU-DET 钢材） | 换成铸件、注塑件，结论不可迁移 | 每种材质一套数据集，别混在一起算 |

**最重要的一条**：105 张、99% 命中，不代表产线能跑 99%。这是**离线回归**，作用是"改动方向对不对"，不是"产线良率多少"。混淆这两件事，面试一问就穿。

## 八、怎么扩展

**补缺失的两类**（最快，1 小时）

```bash
# 把 rolled-in_scale_*.jpg / scratches_*.jpg 放进
# TestImages/RealParts/NEU-DET/data/NEU-DET/test/images/
# 然后重新生成 dataset.json 里的条目（保留已有条目的 sha 不变）
```

**补 good 样本**（价值最高）

没有 good 样本，就永远算不出过杀率 —— 而产线最疼的往往是过杀，不是漏检。有真实正常件图后，在 `GoldenDataset` 里加一个 `expected: "good"` 的类别，`Judge` 里加一条分支：`good` 且零框 = Hit。

**升级到框级评估**

把图像级真值换成 YOLO 格式标注（`class cx cy w h`），判定规则从"有没有该类框"升级为"IoU ≥ 0.5 且类别正确算 TP"。这一步做完，指标就能和论文/竞品直接对标。

## 九、面试怎么讲

> "视觉算法改了之后准不准，不能靠眼睛看。我建了个黄金样本库：105 张钢材缺陷图，清单里锁了每张图的内容哈希，防止样本被悄悄换掉。跑批走的是真实的 Pipeline 和预处理链路，不是直接调模型。每张图判成命中、错分、漏检三态——把错分单独拆出来，是因为它和漏检的改法完全不同。跑完自动和基线比对，输出『新漏检几个、修复几个、误报框增减多少』，退出码非零表示有回归，可以直接当 CI 门禁。目前 99% 命中、1 个漏检、14 个跨类误报框，缺两类样本和 good 样本，过杀率还测不了——这是我下一步要补的。"

这段话的杀伤力：**大部分人会答"我测了一些图"，你能答出指标、边界和下一步。**
